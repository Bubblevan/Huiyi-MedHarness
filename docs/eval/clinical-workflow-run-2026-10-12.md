## 医学证据 ID 与引用支持评估

本轮前的阻塞点是检索来源没有稳定、可供回答引用的 ID。已在 Health Engine 为每个检索片段生成 `MED-<16位十六进制>` ID，ID 由语料、源文档、chunk 和片段原文的 SHA-256 绑定；DSH 收到这些 ID 后按 `[evidence:<ID>]` 输出，并被要求列出检索命中及标明未用于支持主张的来源。这样来源关联率从“没有可识别 ID”变为可核对。

本轮证据引用核对结果：

- Integrated 检索返回 6 个片段 ID，回答含 12 个引用标记。
- 严格同轮匹配为 6/12（50%）：另 6 个标记出现在同一合成患者、同一执行臂的后续轮次，ID 与前一轮 RAG 返回结果完全一致。按“当前轮或同一患者会话此前已检索”的会话口径，来源 ID 可解析为 12/12（100%）。不跨患者、不跨执行臂，也不使用未来轮次结果。
- 证据任务的同轮引用覆盖率仍为 Integrated 1/2、Single 0/3。第二个 Integrated 证据检索轮次未在该轮引用，之后一轮才引用前轮来源，所以会话 ID 可解析率不能替代任务内覆盖率。
- Single-agent 未检索或输出引用标记，因此其“引用 ID 有效率”是 0/0、不可计算；缺失来源以覆盖率 0/3 如实呈现。
- 医学证据“有效率”必须拆成两个指标：**来源可追溯性**和**引用是否支持相邻主张**。稳定 ID 解决了此前没有可识别证据 ID、无法把回答引用映射回原文的问题；ID 可解析本身不等于语义支持。
- 为补上语义支持测量，本轮从运行记录中的 6 个被引用 ID 离线重建并校验出对应 StatPearls 原文片段，制作了不含实验臂、病例和轮次身份的盲化评分包，由隔离的模型辅助工程评分器按固定标准逐条判断。6 个回答正文引用中，**直接支持 3/6（50%）**、**部分支持 3/6（50%）**、不支持/矛盾/无法判断 0/6；若把部分支持也纳入“至少部分有来源支持”，则为 **6/6（100%）**。这只是 2 个 Integrated 回答轮次中的 6 个引用出现，不是临床审核或医学有效性验证；Single-agent 没有引用，不能形成对照。
- 因此，原先的“不可测”已按两层处理：稳定、内容绑定的 `MED-…` ID 使来源识别可测；有限样本的盲化模型辅助 passage review 使本轮 claim-to-passage 支持性可初步量化。更大样本、人工临床复核和临床正确性仍未测量。不能把 50%/100% 外推到全系统或简历级临床效果。
