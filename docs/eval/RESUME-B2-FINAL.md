## 评分口径与限制

评分由隔离子 Agent 在 A/B 标签盲化后执行，是模型辅助的合成工程评分，不是医生审核。评分使用了实际检索片段；4 份较长回答的末尾来源列表在评分副本中被替换为移除标记，因此主张支持结果只覆盖评分副本中可见的主张。29/29 引用 ID 同轮解析来自原始运行 trace，单独计算；它证明 ID 关联存在，不证明临床结论正确。

这是 10 个开发集配对任务，每病例仅一个循证任务。1 个 Integrated 回合没有调用成功检索，但仍保留在分母。观测 token 不是货币成本；没有进行临床审核或外部盲评。另一个 6 条记录的早期试跑没有按协议启用迭代检索，已标记 `invalid-protocol` 并保留，未计入本结果。
