# B2｜医学知识检索与循证生成：首轮证据冻结

## 决定

**状态：`INFRASTRUCTURE_VERIFIED / QUALITY_CLAIM_INSUFFICIENT_EVIDENCE`。** 本机五源 FAISS 医学索引有文件级核验，检索 smoke 和来源 ID 链接均有记录；现有数据不足以声称答案证据支持率提升、95% 引用正确率或医学问答准确率提升。本卡只冻结现有结果，不触发新下载、索引构建或模型生成。

## 已验证的索引与检索链路

- **索引：823,450 个 chunk，5 个来源**，使用 Qwen3-Embedding-0.6B 与 FAISS。分项为 Textbooks 125,847、StatPearls 384,050、PubMed 280,070、Wikipedia 33,414、慧宜医院官网公开页面 69。PubMed/Wikipedia 是本机部分快照；慧宜来源是公开网页，不是患者 EMR。
- **索引核验：** 2026-10-11 verifier 结果为 `verified`；manifest SHA-256 为 `ccc89d1f6deef68536647541fbad6c79c98f7185cfbe2cd0c00698b15f5b37cf`。chunk 数是向量索引记录数，不是独立医学结论数。
- **双语检索 smoke：** 固定 2 个中英文查询，2/2 返回 3 条证据；测得单次检索延迟 283.1–283.9 ms，无答案生成。样本不足以报告 P95，也未评估检索相关性或证据充分性。

## 当前可写与不可写

可以描述索引规模、来源组成、固定 smoke 结果和稳定来源 ID 实现。不得把 chunk 数写成独立文献/知识条数，不得声称 `79%→92%`、`95% 引用正确率`、RAG 带来的答案准确率提升，或把模型辅助工程评分写成临床审核。

**简历候选（基础设施口径，效果提升尚未成立）：**

> 基于 Qwen3-Embedding-0.6B 与 FAISS 构建并核验 823,450 个医学知识 chunk 的五源本地索引；中英固定检索 smoke 2/2 返回 3 条证据（单次 283–284 ms）。GPT-6-Luna 集成运行中，同轮来源 ID 精确匹配 10/20（50%），证据任务同轮引用覆盖 2/4（50%）；医学主张的原文支持率在当前版本尚未测量。
