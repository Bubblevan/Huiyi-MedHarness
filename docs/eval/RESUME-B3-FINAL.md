## 可写结论与限制

- **可写的事实：** 在 3 例合成纵向病例、12 个跨就诊历史事实机会中，Single 与 AMA-only 的精确回答回显均为 0/12；当前这次隔离评测未证明 AMA 带来回答级历史事实收益。
- **不可写的效果：** 不声称 AMA 将正确病史引用率提高了任何百分点；不声称本次多专家协作带来关键点覆盖提升；不把盲化模型评分称为医生审核。
- **协作测试的局限：** 实验入口允许协作能力，但没有触发协作工具。若未来要评估多专家质量，需先修复或明确路由触发问题，再以新的冻结运行比较；本轮按停止规则不继续开发或重跑。
- **成本口径：** 报告的是模型可观测 Token 数，不是 API 美元成本。超时任务可能没有可观测 Token 记录，故两臂总 Token 不代表同等完成工作量。
- **外推范围：** 小样本 development 合成工程评测；无真实患者、无临床审核、无 held-out 临床效能结论。
