## 来源 ID 的不可测问题处理

已用内容绑定的 `MED-<16位哈希>` 为检索证据建立稳定 ID，并要求答案使用 `[evidence:<ID>]`；评估器将该 ID 与本轮 RAG 返回集合精确匹配。因此“是否引用了本轮真实检索到的来源”现在可测。它仍不能回答“来源段落是否支持这句话”，该项需独立的盲化 claim-to-passage 评分，当前明确写作不可测。实现说明：[evidence-citation-id-resolution.md](evidence-citation-id-resolution.md)。
