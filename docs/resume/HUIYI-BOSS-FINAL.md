# 慧宜医疗｜临床 Agent 与医学知识增强工作台

**项目经历｜2026.10**

- 构建临床 Agent 复诊工作流，串联患者与就诊上下文、病史整理、循证检索及供医生审核的结构化草稿；设计 300 例异构合成纵向病例候选集，覆盖 15 个工作流领域、2–4 次就诊、历史依赖、信息缺口、来源冲突与风险信号，待人工审阅后开展配对评测。
- 构建五源、823,450 段本地医学知识索引，基于 Qwen3-Embedding 与 FAISS 实现多轮检索；在 10 个固定开发集循证任务中，RAG 任务满足率由 1/10 提升至 10/10，29/29 个回答引用 ID 可回溯至同轮检索结果。
- 完成长对话记忆与 DSH 会话的工程集成，核验 MemorySnapshot 和来源引用逐题一致；在 3 段完整长对话、385 道 QA 的诊断评测中，Token-F1 为 0.4408，782/792 条记忆来源引用有效。
- 搭建本机 Docker Compose 边缘工作台原型，串接 HTTPS、登录鉴权、患者/就诊上下文授权及 SSE 代理；在 300 例合成患者的 600 次授权检查中，越权读取 0 次。

**评测范围：**以上效果数字来自合成工程评测或本机验证，不代表临床有效性、真人医生审核或公网生产部署。医学证据对结论的支持有效性在 B1 评测中不可测。后训练成果待实际训练与独立评测后补充。完整口径与限制见[面试证据备忘录](HUIYI-INTERVIEW-EVIDENCE.md)。
