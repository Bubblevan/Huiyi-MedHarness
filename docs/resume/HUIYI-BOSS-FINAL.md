# 慧宜医疗｜临床 Agent 与医学知识增强工作台

**项目经历｜2026.10**

- 构建临床 Agent 工作流，串联患者与就诊上下文、长期记忆、医学检索、多专家协作及医生审阅草稿；在 6 例合成纵向病例的 48 组配对任务中（保留 7 次执行失败），Integrated 关键任务完成率由 **54.2% 提升至 66.7%（+12.5 个百分点）**，两臂共同披露的 44 组既往事实正确引用率由 **43.2% 提升至 68.2%（+25 个百分点）**。
- 构建 **823,450 段、五源**本地医学知识索引，接入 Qwen3-Embedding 与 FAISS 多轮检索；在 10 个固定合成循证任务的配对模型辅助工程评分中，任务满足率由 **1/10 提升至 10/10（+90 个百分点）**，29/29 条输出引用 ID 可回溯至同轮检索结果。
- 交付 Docker Compose 本地边缘演示，覆盖 HTTPS 工作台、会话鉴权、患者/就诊授权与 SSE 代理；在 300 例合成患者的 **600 次上下文授权检查中越权成功 0 次**，边缘 API 并发 20 时 **20/20 成功**，并完成 1 次 GPT-6-Luna + 本地 RAG 浏览器问诊、证据展示、结构化草稿及审阅留痕流程（46.6 秒）。

**评测范围：**以上效果数字来自合成数据的内部工程评测，不是临床审核或真实患者效果；边缘演示在本机完成，尚未对公网发布。完整分母、版本、实验限制及 B3 结论见[面试证据备忘录](HUIYI-INTERVIEW-EVIDENCE.md)。
