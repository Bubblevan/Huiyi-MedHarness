# Huiyi MedHarness｜简历项目段（证据约束草稿）

**医疗 Agent 系统开发负责人**　2026.07–2026.10

**技术栈：** TypeScript、Python、DeepSeek Harness、GPT-6-Luna、Qwen3-8B（独立旧版 MedQA 验证）、Qwen3-Embedding-0.6B、FAISS、本地 Gateway、vLLM（旧版验证环境）

**项目介绍：** 面向互联网医院连续问诊与复诊场景，构建本地医疗 Agent 工作台，打通合成患者上下文、长期记忆、医学知识检索、多专家协作、复诊草稿和工作台鉴权；通过固定 Cohort 与 Single/Integrated 配对评测验证工程行为。

- **临床 Agent 工作流：** 基于 GPT-6-Luna 与 DeepSeek Harness 运行 6 例合成纵向病例、48 对计划复诊任务（7 条执行失败保留在分母中），关键任务完成率由 54.2% 提升至 66.7%（+12.5 个百分点）；Integrated 执行成功率为 87.5%，因此该结果是早期工程信号，不代表临床效果。
- **医学知识检索：** 构建并验证 Qwen3-Embedding-0.6B/FAISS 五源索引，共 823,450 个文本片段；当前索引中英 single-pass smoke 2/2 通过，另有一次两轮迭代检索通过；独立 MedCPT 旧版 509,897 段快照的 100 条冻结查询中，Top-1、Top-32 和排序结果与 pinned MedRAG 匹配率均为 100%。
- **纵向病史与协作：** 对两臂共同披露的 44 组既往事实进行盲化判定，正确引用率由 43.2% 提升至 68.2%（+25 个百分点；13 胜、2 负、29 平）；另在一次高级合成病例 smoke 中完成 6/6 个协作子任务。
- **患者级访问控制：** 在 300 例合成数据的 600 次本地上下文访问检查中，150 次授权、450 次拒绝，越权读取 0 次（只读请求 P95 2.59 ms）；一次本地浏览器端到端流程完成 GPT-6-Luna、RAG、结构化复诊草稿和审阅留痕（HTTP 200，47.7 秒）。

## 暂不放入对外简历的目标项

- **SFT / LoRA / GRPO：** 当前只有 Qwen3-8B Q4 GGUF 推理文件，没有已验证的可训练 checkpoint、当前 Python 环境缺少 PEFT/TRL 等训练依赖；没有训练步骤或独立质量评测，因此不写训练提升。
- **云端生产部署：** 现有证据是本机合成 Gateway 和浏览器链路；没有阿里云公网部署、WireGuard、生产 HTTPS、生产身份系统或并发 SLA 结果，因此不写“已部署生产环境”。
- **循证质量：** 尚未测得医学证据支持率或引用正确率；检索 parity 不是答案证据支持率，不能填写目标中的 79%→92% 或 95%。
