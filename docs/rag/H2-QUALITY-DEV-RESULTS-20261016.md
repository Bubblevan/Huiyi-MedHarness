# H2-RAG-QUALITY：V12 DEV 检索质量结果（2026-10-16）

## 结论

表现指标此前没有产出，主要原因不是样本量本身，而是检索候选缺少可计算的相关性标签（qrels）。这次在固定 100 题 DEV 集上运行盲化 GPT-6-Luna Judge，得到 1,769/1,786 条候选有效标签，覆盖率 98.99%；17 条保留为不可判，1 条低置信语义标签经第二遍盲评后仍因标签与解释矛盾而待审。没有把未判候选当成不相关。

在完整候选池标注的 87/100 题上，已计算 A–D 的 pooled-qrels 排序指标。当前结果是**DEV 探索结果**，不是冻结 HOLDOUT 结论，也不是临床准确率。Reranker 改善了前 5 位的排序和首个直接支持结果的位置；它相对 Dense 的 nDCG@10 差异尚不能证明总体提升。单独 RRF 在本 DEV 集上显著低于 Dense。

## 固定实验条件

- 数据集：`h2-quality-v12-dev-20261015`，100 道 DEV 检索问题；无来源冲突题，10 道 no-answer 问题来自合成病历字段。
- 语料：冻结的五源本地语料，`medtext-local-cc7d43568501e6b7`，823,450 chunks；Qwen3-Embedding-0.6B + FAISS。未下载语料、未重建索引。
- 候选池：每题对 A–D 运行结果形成匿名 pooled candidate set；方法、排名和检索分数对 Judge 隐藏。评分仅针对候选池，不称作全库绝对 Recall。
- 方法：A Dense；B BM25；C Dense+BM25/RRF；D RRF 候选 + BGE Reranker。每种方法共用固定检索语料和结果预算。
- Judge：本机 Codex GPT-6-Luna CLI；grade 0/1/2 分别表示无关、局部/主题相关、直接支持。正相关判断须给出候选原文中的逐字短引文。
- 外部 Gold 一致性：不可得；没有人工专家审核。本报告中的 Judge 结果是工程相关性标签，不是医疗专业意见。

| 方法 | nDCG@10（n=86） | MRR@10（n=87） | P@5（n=75） | Pooled Recall@10（n=75） |
|---|---:|---:|---:|---:|

配对差异（差值为前者减后者）：

| 对比 | 指标 | 配对题数 | 均值差 | 95% 配对 Bootstrap CI |
|---|---|---:|---:|---:|

| RRF − Dense | MRR@10 | 87 | −0.0728 | [−0.1292, −0.0160] |
| Reranker − Dense | nDCG@5 | 86 | +0.0927 | [+0.0566, +0.1316] |
| Reranker − Dense | MRR@10 | 87 | +0.1258 | [+0.0661, +0.1906] |
| Reranker − Dense | P@5 | 75 | +0.0507 | [+0.0240, +0.0800] |
| Reranker − Dense | Pooled Recall@5 | 75 | +0.1147 | [+0.0585, +0.1796] |

## Bad Case 与根因状态

已生成 18 个逐题案例，其中 15 个属于可观察到的方法排序退化，另 3 个是无答案问题的检索边界风险。分组：

- BM25 跨语言退化：5 例；双语类 BM25 nDCG@10 为 0.1058，Dense 为 0.9201。
- RRF 融合退化：4 例；记录同一 query 上的 Dense/RRF nDCG 和 Top-5 文档排序。
- Reranker 退化：3 例；记录重排后 nDCG 下降的 query。
- Dense 排序弱项：3 例；候选池已有直接支持文档，但 Dense 排序指标偏低。
- 无答案检索边界风险：3 例；问题针对合成病历字段，外部医学语料返回主题相近内容；本轮未生成答案，因此不称作错误医学回答。

每个案例都附 query、任务类、各方法 nDCG@10、Top-5 文档 ID/来源/相关性等级、直接支持文档和原因假设。根因尚未通过参数干预验证；没有把假设写成已证实因果，也没有宣称修复效果。

## 评测边界与剩余工作

1. **DEV 表现结果已由冻结 HOLDOUT 复核。** 200 题 HOLDOUT 的 A–D 检索已完成；6,973/6,991 候选标签有效（99.74%），182 题符合 nDCG/MRR 计分条件。RRF + Reranker 相对 Dense 的 nDCG@10 配对差为 +0.0915（95% CI [+0.0659, +0.1177]），因此 `QUALITY_IMPROVEMENT_DEMONSTRATED=YES` 仅适用于检索排序质量。H2 整体仍未完成：E/F、生成答案支持度和来源冲突评测尚缺。
2. **来源冲突覆盖为 0。** 适用人群/范围边界不是来源冲突，不能混称。当前五源数据中还没有经过核实的成对矛盾来源题。
3. **E / F 未完成。** 当前 8333 Planner API 返回 401；还没有使用 Codex CLI 适配器实际跑完 Iterative Retrieval，也没有运行自适应证据充分性 F。
4. **答案生成支持性未完成。** Judge 已评候选段落是否支持查询，但尚无固定生成模型产出的回答，因此没有 claim-level faithfulness、citation validity、unsupported-claim rate 或拒答率数字。
5. **没有临床准确率或外部 Gold 一致性结论。** 无人工临床审核，也无专家外部相关性标注集。
6. 数据问题修正：早期 V11 草稿中存在未替换的 `[GENERATE:...]` 查询，相关运行已排除；本结果绑定 V12 数据哈希，不拼接早期运行。
